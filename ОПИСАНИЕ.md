# 🐌 Улитка

## Русский язык программирования

«Улитка» — экспериментальный язык программирования,
создаваемый с нуля.

## Цель

Создать язык программирования, в котором пользователь
может писать программы на русском языке.

## Первая целевая платформа

Браузер.

## Результат компиляции

HTML
CSS
JavaScript

## Версия языка

0.1

## Состояние проекта

Проект находится на стадии разработки.

## Главный принцип

Пользователь пишет программу на языке «Улитка»,
а компилятор самостоятельно преобразует её
в код, необходимый для запуска программы.

## Автор

Личный экспериментальный проект.
